# 🤖 로보중국어 (RoboChinese)

듀오링고 방식으로 배우는 **로봇 산업 실무 중국어** 학습 게임입니다. 선전(深圳) 로봇밸리 전시 자료와 2026 휴머노이드 로봇 산업 리포트에서 뽑은 실제 업계 표현으로 구성했습니다.

**👉 https://<GitHub사용자명>.github.io/robo-chinese/ 에서 접속**

## 📱 아이폰에 앱처럼 설치하기

1. 사파리로 사이트 열기
2. 하단 **공유 버튼 → 홈 화면에 추가**
3. 홈 화면 아이콘으로 실행 — 인터넷이 없어도 작동합니다(오프라인 저장)

## ✨ 기능

- 문제 유형 7종: 뜻 고르기 · 한자 고르기 · 듣고 고르기(TTS 발음) · 짝 맞추기 · 문장 조립 · 빈칸 채우기 · 문체 변환
- 하트 5개(20분 충전) · 보석 · XP · 연속 학습일 · 일일 목표
- SRS 복습: 틀리거나 약해진 항목 자동 재출제
- 섹션별 가이드에서 전체 원문·병음·번역 열람 (🔊 발음 듣기)
- 학습 기록은 이 기기에 자동 저장 · 기록 탭에서 백업/복원

## 🔧 기술

의존성 없는 순수 정적 웹앱(HTML+JS). 발음은 iOS/브라우저 기본 중국어 TTS를 사용합니다. 기록은 브라우저 localStorage에만 저장되며 서버로 전송되지 않습니다.
